# Generic office layout and design inputs

EnergyPlus 24.2 IDFs are generated by `models/build_generic_office_vav.py` from a **layout** JSON file and optional **design** overrides.

## Layout JSON (`schema_version` 1.0)

| Key | Type | Description |
| --- | --- | --- |
| `schema_version` | string | Must be `"1.0"`. |
| `climate.ashrae_climate_zone` | string | ASHRAE 169 zone label (e.g. `4A`). Used for documentation; design days come from `design_values.json`. |
| `climate.weather_file` | string | EPW file name for annual `RunPeriod` (not embedded in the IDF). |
| `building.floors` | int | Number of conditioned floors. |
| `building.footprint_length_m` | number | Rectangle length (X), meters. |
| `building.footprint_width_m` | number | Rectangle width (Y), meters. |
| `building.floor_to_floor_m` | number | Story-to-story height. |
| `building.total_area_m2` | number, optional | Target gross area; geometry uses footprint × floors if omitted. |
| `ahus[]` | array | One packaged VAV air handler per floor (default generated if empty). |
| `ahus[].id` | string | Air loop name prefix (e.g. `ahu-1`). |
| `ahus[].floor` | int | Served floor index (1-based). |
| `ahus[].gas_preheat` | bool, optional | If true, add `Coil:Heating:Fuel` upstream of the supply fan. |
| `ahus[].vavs[]` | array | Terminals on this AHU. |
| `ahus[].vavs[].id` | string | VAV / ADU name prefix. |
| `ahus[].vavs[].zone` | string | EnergyPlus zone name. |
| `ahus[].vavs[].floor` | int | Zone floor (1-based). |
| `ahus[].vavs[].reheat` | string | `electric` (default) or `hot_water` (`Coil:Heating:Water`). |
| `ahus[].vavs[].perimeter` | string, optional | `north`, `east`, `south`, `west`, or `core` for footprint split. |

### Default topology

When `ahus` is omitted, the generator creates **two AHUs** (floors 1–2) with **five VAVs** each: four perimeter zones plus one core zone. Perimeter depth defaults to ~4.5 m, capped by footprint size.

Example: `models/layouts/default_two_story_office.json`.

## Design values (`design_values.json`)

Optional file passed with `--design`. Keys override generator defaults.

| Key | Default | Purpose |
| --- | --- | --- |
| `lighting_w_per_m2` | 10.8 | Medium office lighting power density. |
| `equipment_w_per_m2` | 10.8 | Plug / process equipment power density. |
| `people_per_m2` | 0.05 | Occupant density (people / m²). |
| `story_height_fraction` | 0.88 | Zone height as fraction of floor-to-floor. |
| `window_wall_ratio` | 0.35 | Approximate glazing fraction on exterior walls. |
| `wall_u_value`, `roof_u_value`, `floor_u_value` | 0.35 / 0.25 / 0.3 | Envelope targets (simplified constructions). |
| `site_name`, `latitude`, `longitude`, `time_zone`, `elevation_m` | Chicago OHare | `Site:Location`. |
| `winter_design_db_c`, `summer_design_db_c` | -17.3 / 33.3 | `SizingPeriod:DesignDay` dry bulb. |
| `timesteps_per_hour` | 6 | Simulation timestep (default annual path). Use **60** for 1-minute zone timestep runs. |
| `run_period` | (annual) | Optional `{name, begin_month, begin_day, end_month, end_day}` to shorten weather runs (representative week). |
| `simulation_control` | (all Yes) | Override `SimulationControl` flags (`do_zone_sizing`, `run_sizing_periods`, …). Minute week sets sizing periods **No**, weather **Yes**. |
| `skip_sizing` | false | Deprecated alias: all sizing off, weather on (do not use with autosize templates). |
| `supply_air_temp_min_c`, `supply_air_temp_max_c` | 12.8 / 15.6 | `SetpointManager:Warmest` SAT reset band. |
| `duct_static_pressure_min_pa`, `duct_static_pressure_max_pa` | 250 / 450 | `SetpointManager:StaticPressure` band. |
| `fan_pressure_rise_pa`, `fan_max_flow_m3_s` | 600 / 5.0 | Supply fan sizing hints. |
| `cooling_*` | see file | DX single-speed coil autosize hints. |
| `gas_preheat_capacity_w`, `gas_preheat_efficiency` | 20000 / 0.8 | Optional gas preheat coil. |
| `vav_max_flow_m3_s`, `vav_min_flow_fraction` | 0.35 / 0.2 | Terminal max / minimum flow. |
| `reheat_capacity_w`, `reheat_max_flow_fraction` | 8000 / 1.0 | Zone reheat coil. |
| `design_heating_supply_c`, `design_cooling_supply_c` | 16 / 13 | `Sizing:System` supply air temperatures. |

## Generated HVAC features

- `AirLoopHVAC` per AHU with `Fan:VariableVolume`, `Coil:Cooling:DX:SingleSpeed`, optional `Coil:Heating:Fuel`
- `Controller:OutdoorAir` differential dry-bulb economizer on an `OutdoorAir:Mixer`
- `AirTerminal:SingleDuct:VAV:Reheat` with electric or hot-water reheat
- `SetpointManager:Warmest` and `SetpointManager:StaticPressure` per air loop
- `Sizing:Zone`, `Sizing:System`, and `DesignSpecification:OutdoorAir` (ASHRAE 62.1-style people + area method, simplified)
- `Output:Variable` requests aligned with `generic_office/points.py` for BACnet-style mapping (no EMS)

## RDF / Turtle (`models/rdf_to_layout.py`)

Shipped example: `models/sample_building.ttl` (Brick + Haystack tags + ASHRAE 223P roles).

```bash
python3 models/rdf_to_layout.py models/sample_building.ttl -o models/generated/layout.json
```

Triples use one predicate per line (`ex:rtu-1 brick:feeds ex:vav-f1-core .`). The converter discovers AHUs (`brick:Rooftop_Unit`), VAVs (`brick:VAV`), zone feeds, reheat type, and floor metadata.

## `design_values.json` (post-autosize)

Stable machine-readable keys for functional-test fallbacks when BACnet/nameplate data is missing. All scalar capacities use `{ "value": <float|null>, "unit": "<SI>" }`.

| Path | Description |
| --- | --- |
| `schema_version` | Always `1.0`. |
| `units` | Unit strings for documented fields. |
| `climate` | Echo of layout climate. |
| `ahus[].id` | Layout AHU id (`ahu-1`, `rtu-1`, …). |
| `ahus[].design_supply_airflow_m3_s` | Design primary air from system sizing. |
| `ahus[].fan_design_static_pressure_pa` | Fan design pressure rise. |
| `ahus[].fan_design_power_w` | Fan design shaft/brake power when available. |
| `ahus[].cooling_capacity_w` / `heating_capacity_w` | Coil autosize results. |
| `ahus[].minimum_oa_flow_m3_s` | Minimum outdoor-air design flow. |
| `vavs[].id` / `zone` / `reheat_type` | Terminal metadata. |
| `vavs[].max_airflow_m3_s` / `min_airflow_m3_s` | Terminal flow limits. |
| `vavs[].reheat_capacity_w` | Zone reheat coil capacity. |
| `pumps[]` | Plant pumps when present (`design_flow_m3_s`, `design_head_pa`, `design_power_w`). |
| `loops[]` | Plant loops (`design_loop_delta_p_pa`). |
| `curves.fans[]` | Part-load **flow / pressure / power** points for operating charts (SI). |
| `curves.pumps[]` | Pump part-load curves when present. |
| `performance` | Annual EUI, electricity, gas, unmet hours; `estimation_method` documents the source. |

## Sizing extraction

`models/run_generic_office.py` runs EnergyPlus with `-x` (ExpandObjects) and writes `design_values.json`, `sizing_summary.md`, and `timeseries_representative_week.csv` (hourly averages of zone-timestep catalog points).

Optional **`--timeseries-minute`**: after the annual autosize run, simulates **Jan 6–12** at `Timestep` **60** (1-minute), exports `timeseries_representative_week_1min.csv` at **Zone Timestep** frequency, and writes `timeseries_minute_week.meta.json` (wall-clock runtime).

## CLI

```bash
python models/build_generic_office_vav.py \
  --layout models/layouts/default_two_story_office.json \
  --design models/generic_office/design_values.json \
  -o models/out/generic_two_story_office_vav.idf
```
